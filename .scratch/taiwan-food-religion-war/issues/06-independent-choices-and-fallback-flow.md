# 06 — 以四次飲食抉擇完成備援流程

**What to build:** 玩家從 Home 進入後，能完成四次彼此獨立的飲食抉擇，檢視完整本局信仰清單，主動觸發不可重抽的辯護抽籤，並針對抽中立場完成辯護與備援裁決。這條 tracer bullet 完整取代舊跨主題淘汰流程，先交付一條不依賴模型或最終視覺資產也能獨立展示、重玩與驗收的端到端路徑。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 從 Home 進入後直接開始第一個飲食抉擇；一局從六組立場題庫隨機選出四組不同題目並隨機排序，測試可控制題目、順序與抽籤結果。
- [ ] 每個飲食抉擇只比較同一主題的兩個飲食立場；整張卡可選，第一個有效選擇立即鎖定兩張卡，顯示「立場已記錄」，短暫回饋後才前進。
- [ ] 四個選擇依序加入本局信仰清單；後續選擇不得淘汰、覆蓋、排名或晉升先前選擇，進度只使用「飲食抉擇 1–4」與抽籤／辯護語意。
- [ ] 四題完成後先完整顯示本局信仰清單並等待玩家觸發抽籤；不得自動跳過「完整清單 → 抽籤行動 → 揭曉」節拍。
- [ ] 辯護抽籤每局只從四項本局信仰清單選出一項、只能執行一次且不可重抽；同一次 App run 候選允許時避免連續兩局抽中相同立場。
- [ ] 抽中結果顯示抽中立場、原位標記及對應的幽默但公平固定質疑；玩家可輸入 1–50 個使用者可見字元，空白或超限不可送出並顯示就地說明。
- [ ] 沒有可用模型時，送出只接受一次並完成安全備援裁決；結果透明揭露備援模式，不假裝分析玩家輸入，也不顯示技術錯誤。
- [ ] 結果頁以抽中立場為主要內容，同時保留完整本局信仰清單，固定顯示「本次抽中；四個選擇都會保留。」並提供主要「再玩一次」與次要「回首頁」。
- [ ] 再玩建立乾淨新 Session；回首頁與確認離開會清除本局；取消離開保留目前題目、信仰清單與抽籤狀態。
- [ ] 玩家可見 production 行為與高層流程測試不再出現或依賴舊的準決賽、決賽、晉級、跨主題淘汰或最高位階結果語意；舊測試須改寫或移除，不能與新版斷言並存。
