# 08 — 提供非阻斷缺少模型提醒

**What to build:** 沒有可用模型時，玩家會看見一次清楚但不阻斷遊戲的提醒，可直接選擇「先玩再說」，也可前往既有推薦模型區；往返模型管理會保留本局並重新偵測模型，下載取消或失敗仍可回到遊戲完成備援流程。

**Blocked by:** 07 — 讓抽中立場使用端側模型裁決.

**Status:** ready-for-agent

- [ ] 沒有可用模型時，每次 App run 只顯示一次「AI 評審還沒來報到」提醒，並清楚表達「不影響遊戲」。
- [ ] 提醒的主要行動固定為「先玩再說」，次要行動固定為「前往推薦模型」；玩家不需安裝模型即可開始及完成遊戲。
- [ ] 玩家選擇「先玩再說」後立即回到目前遊戲任務，本次 App run 不再重複顯示提醒。
- [ ] 提醒關閉後，辯護頁仍保留可見但不搶過固定質疑、模型選擇與輸入的模型入口。
- [ ] 「前往推薦模型」沿用既有模型管理頁並直接抵達推薦模型區，不建立遊戲專屬下載、管理或模型狀態頁。
- [ ] 前往模型管理時保留目前題目、已選立場、本局信仰清單與抽籤狀態；返回後重新發現模型並更新可用模型選擇。
- [ ] 模型下載取消、失敗或返回時仍可繼續遊戲並取得備援結果；底層錯誤、錯誤碼與例外不進入遊戲 UI。
- [ ] 高層流程測試覆蓋首次提醒、同一 App run 不重複、直接繼續、往返模型管理、返回後發現模型及下載失敗備援路徑。
