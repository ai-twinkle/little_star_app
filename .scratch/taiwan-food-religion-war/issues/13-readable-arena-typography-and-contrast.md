# 13 — 修正實機遊戲文字尺寸與對比

**What to build:** 玩家在實體手機上能清楚閱讀「台灣食物宗教戰爭」所有必要文字；深色招牌擂台中的選項、固定質疑、字數、信仰清單與模型控制不得繼承全域亮色主題的深色文字，也不得出現淺色文字配近白元件背景。

**Blocked by:** 11 — 完成自動化響應式與無障礙驗收.

**Status:** completed

- [x] 深色 arena theme 必須涵蓋建立 `Scaffold`／`Material` 預設文字樣式的邊界，或以同等可靠的方式確保所有玩家可見文字取得正確深色主題；不可逐一補色而遺漏其他狀態。
- [x] 選項名稱、固定質疑、字數、輸入提示、模型選擇、信仰清單及結果文字，在實際背景上的一般文字對比至少為 4.5:1；大字至少為 3:1。
- [x] `Chip` 與其他 Material 元件明確使用相容的前景／背景組合，不再出現奶白字配近白底。
- [x] 手機上的一般資訊文字不小於 16 logical px；選項名稱、固定質疑與主要操作文字不小於 18 logical px，且仍尊重系統文字縮放。
- [x] 從 Home 進入真實遊戲 Feature 的既有高層 Widget seam 覆蓋飲食抉擇、抽籤、辯護與結果，以玩家可觀察的渲染結果驗證最低對比與關鍵字級，不依賴私有 Widget 名稱或階層。
- [x] 320 × 568、430 × 932、480 × 960 與 1280 × 900，以及 2× 文字縮放與鍵盤 inset，仍無 overflow、裁切或不可達操作。
- [x] 修正後重新在 iPhone 17 Pro（iOS 26.5.2）檢查同一流程，並由使用者確認文字大小與清晰度可接受。
