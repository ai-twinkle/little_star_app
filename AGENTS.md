## Agent skills

### Issue tracker

Issues are tracked as local Markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

Every new development record — spec, tickets, plans, exploration notes — goes under `.scratch/<feature-slug>/`. Do not open new cycle directories under `.dev/cycles/`: the three there are history that `docs/adr/0005` and `docs/benchmark/*.md` still link to, but the workflow has moved on.

### Triage labels

Use the default canonical triage label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses the single-context domain documentation layout. See `docs/agents/domain.md`.
